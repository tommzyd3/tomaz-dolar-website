- `virtual-reality.html` – VR in simulacije
- `superavti.html` – Ferrari, Lamborghini
- `moda.html` – osebni slog
- `sport.html` – simulacije in šport
- `astronomy.html` – vesolje
- `styles.css` + `script.js` – moderni dizajn in animacije
